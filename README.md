# -_PMUX-
本项目面向国产FPGA逻辑综合多路选择网络资源优化，研发基于Yosys的PMUX结构优化引擎。系统以形式等价为正确性约束，以统一映射流程下电路单元数量为优化指标，通过自定义Tcl命令调用C++插件，完成PMUX识别、位片段分析、选择条件共享与候选结构重构。项目挖掘宽位选择网络中重复数据与控制条件的复用机会，依靠映射代价筛选有效变换方案，结合EQY实现变换验证、反例定位与自动回归。针对单级PMUX与混合组合逻辑场景，在功能等价前提下，目标相对基准流程缩减电路单元10%以上，冲刺20%；节点≤1000的测试场景中，优化耗时≤60秒、峰值内存≤2GB。项目产出可复现插件、验证脚本、测试集与实验报告，为国产FPGA综合工具链提供可验证、可评估的多路选择网络优化方案。
