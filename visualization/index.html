源端未指定触发器初态按逻辑 0 处理，显式初值保留；候选端不添加 zinit / setundef 修补。这不等同于任意初态下的普遍等价。

test2 按 Yosys read_verilog / proc 综合语义解释，不宣称等同原 RTL 不完整事件敏感列表的仿真。历史基线 test4 反例不会被本平台改写为 PASS。

03 / 算法与器件

有条件的局部改写

opt_pmux 对控制输入数量、位宽、拓扑、保护属性与资源收益设置边界。不能证明条件时跳过重构。

R30 含 Cyclone IV SCLR / SLOAD 目标路径。既有有限 ModelSim 检查不证明 SDF 时序；本平台不声称已有 EQ6HL130P 器件实测结果。
