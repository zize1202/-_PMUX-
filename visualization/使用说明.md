# PMUX R30 算法探索台

解压工程后，双击本目录的 `index.html`，使用 Edge、Chrome 或 Firefox 等现代浏览器打开。无需安装、联网或启动本地服务。请将同目录的 HTML、CSS、JS 文件一起保留。

这是独立的算法说明平台，不是原工程前端，不连接、运行或修改 Yosys、EQY、eLinx 或任何原工程文件。

- **项目概览**：展示优化流程和已保存的单批次数据。
- **算法实验室**：选择器恢复、四路零默认优先链分组、共享操作数加法；可切换输入、位宽、控制冲突并播放/单步查看。表格枚举该教学模型全部控制状态。实验室不是完整 C++ 优化器的浏览器移植。
- **九例结果**：切换逻辑单元、全部叶单元、综合时间、峰值工作集，筛选、排序和查看逐例明细，导出当前表格 CSV。
- **来源与边界**：查看原始报告路径、提取时 SHA-256、证明契约及数据快照 JSON 导出。

## 数据口径

数据提取自输入工程 `FINAL_DELIVERY/current_reproduction` 的 `measure/report.json`、`strict/report.json` 和总报告，批次 `r20261102_072425_992b5bb8`。这些是已有记录，不是清理工程后重新运行得到的结果。

36.252247% 是九例 **LUT + 反相器** 缩减率的算术均值，不是全部叶单元降幅。全部叶单元包含触发器。面积导出不纳入计时，时间是原报告两条命令综合进程生命周期，内存是峰值工作集。MiB 使用 2²⁰ 字节。

EQY 的 PASS 受原始证明契约约束：源端未指定 FF 初态采用逻辑 0、保留显式初值，候选端不做 zinit / setundef 修补。test2 按 Yosys 综合语义理解，不等同于原 RTL 不完整敏感列表的事件仿真。当前严格证明 runner 的 baseline 槽装载当前候选，不能把该字段当成原默认基线通过证明。

本组测量对应 synth_intel / Cyclone IV 映射，不表示中科亿海微 EQ6HL130P 实测 PPA。有限 ModelSim 仿真不能替代形式证明或 SDF 时序验证。

原始 SHA-256 标记的是提取时来源；注释清理、包清单更新后同名文本文件可能有不同哈希。`data.json` 与 `data.js` 保存提取快照，不依赖报告文件路径可访问。
